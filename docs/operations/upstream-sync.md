# Repository workflow

Project-MMG/upcomputer is the development and review repository. Use its GitHub issues, branches,
and pull requests for changes to this fork. [Contribution guide](../../CONTRIBUTING.md)

Check `git remote -v` in an existing checkout. If `origin` points to another repository, update
its URL to the Project-MMG fork before the next pull or push.

```sh
git remote set-url origin https://github.com/Project-MMG/upcomputer.git
git remote -v
```

This code descends from [Up.computer](https://github.com/krl-gr/upcomputer) and
[T3 Code](https://github.com/pingdotgg/t3code). Evaluate fixes from related projects through the same
issue, review, and verification process as any other change.
